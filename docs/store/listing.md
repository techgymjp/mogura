英語版は `listing-en.txt` にまとめています。

- パッケージ名: `jp.techgym.mogura`
- カテゴリ: ゲーム ＞ アーケード
- プライバシーポリシー: 日本語 https://techgym.jp/privacy-policy/ ・英語 https://techgym.jp/privacy-policy-en/
- コンテンツのレーティングの参考: 刀で斬る・人物が飛ばされる描写はあるが、血や流血の表現はない（デフォルメした漫画風の暴力）。歴史上の人物を題材にしている

## 日本語

**アプリ名**（30 文字以内）

```
本能寺の変モグラ叩き
```

**簡単な説明**（80 文字以内）

```
光秀と本能寺の変の黒幕を叩け！ただし白い浴衣の信長だけは叩くな。燃える本能寺が舞台の和風モグラ叩き。
```

**詳しい説明**

```
天正十年六月二日、未明。「敵は本能寺にあり」――。
炎に包まれる本能寺で、穴から次々と顔を出す人物たちを叩きまくれ！
明智光秀、そして本能寺の変の「黒幕」と噂される人物を成敗して、戦功を上げよう。
ただし、白い浴衣の御屋形様（織田信長）を叩いたら、その場で終わり。

■ 叩くべき相手
・明智光秀（+5）…刀を振りかぶって斬りかかってくる
・羽柴秀吉（+2）…千成瓢箪を振って跳ね回る
・徳川家康（+2）…腕組みでうたた寝し、はっと目を覚ます
・足利義昭（+2）…密書を書き、左右をうかがう
・朝廷の公家（+2）…扇で口元を隠して「ほほほ」
・イエズス会の宣教師（+2）…十字架を高く掲げる
・比叡山の僧侶（+2）…薙刀を振り回す

■ 叩いてはいけない相手
・森蘭丸（-3）…両手を振って「味方です！」と慌てる
・白い浴衣の信長（即終了）…扇を手に敦盛を舞う。叩くと激怒する

■ 成敗の手応え
・叩くと刀の斬撃と火花が走り、人物は目を回して宙へ吹き飛ぶ
・光秀を討ち取ると、画面が光って大きく揺れる
・続けて叩くと連撃ボーナス。逃がすと連撃は途切れる

■ 一筋縄ではいかない出方
・半分だけ顔を出して引っ込むフェイント
・出てきそうで出てこない、じらしの出方
・ひょっこり一瞬だけ、同じ穴から二度出し
・なかなか引っ込まない、おバカな居座り
・時間がたつほど炎が強まり、出入りも速くなる

■ 和の世界観
・肖像画をもとに描いた人物を、1コマずつポーズを描いた12コマのアニメーションで
・入母屋造の本堂が燃え上がり、火の粉と煙が舞う
・BGMは尺八と三味線。炎上が進むほどテンポが上がる

■ その他
・制限時間30秒。「天下布武」から「是非に及ばず」までの称号
・ベスト記録の保存、結果のシェア
・信長を叩いてしまったら、広告を見て叩く前まで時を戻せる（1ゲーム1回）
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

本能寺の変の真犯人は誰だったのか。叩いて確かめろ！
```
